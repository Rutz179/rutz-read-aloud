# Rutz's Read Aloud

[Discord](https://discord.gg/bB7Ca666Bv) · [Wiki](https://github.com/Rutz179/rutz-read-aloud/wiki)

Reads Foundry VTT chat aloud on your own computer, so text play is easier to follow. Each player turns it on for themselves; the voice comes from their browser and only they hear it.

- **Typed lines only** — talk, emotes and whispers to you; rolls and system cards are skipped.
- **Character voices** — a voice and pitch per character, or a different one for each automatically. The GM can set them once for everyone.
- **Keys** — Alt+S stop · Alt+R say the last line again · Alt+T on/off.
- Natural voices in Microsoft Edge. Any game system.

## Install
Foundry → *Add-on Modules* → *Install Module* → Manifest URL:
```
https://github.com/Rutz179/rutz-read-aloud/releases/latest/download/module.json
```
Foundry VTT v13–v14 · any system · a browser that can speak text · English / 한국어

*Configure Settings → Rutz's Read Aloud → On/off, voice, speed*, or Alt+T.
